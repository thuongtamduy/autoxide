## D-20261121-s3-client · Lưu file: `rusty-s3` + `reqwest` cho S3, ổ đĩa tự viết, thay `object_store` — 2026-11-21 — agent quyết

Chủ đề: Module nội dung, file, liên lạc

Quyết định: module `files` bỏ `object_store` (kéo `humantime`, bị RustSec gắn "không còn bảo trì", RUSTSEC-2026-0542 —
D-20261121-time-library). Hai nơi lưu sau trait `Storage` của kernel, cùng hành vi như trước:

- **S3 / dịch vụ tương thích S3** (`modules/files/src/store/s3.rs`): `rusty-s3` 0.12 dựng và ký request (AWS SigV4,
  link ký có hạn 15 phút cho request của máy chủ), `reqwest` sẵn có gửi. Địa chỉ kiểu đường dẫn
  (`<endpoint>/<bucket>/<khoá>`, mặc định `https://s3.<region>.amazonaws.com`) như `object_store` trước đây. File nhỏ hơn
  8 MiB ghi một lần; lớn hơn ghi multipart 8 MiB / phần, bị bỏ giữa chừng thì huỷ (D-158). Đọc theo luồng, `Range` cho
  đoạn, `HEAD`, xoá (không có coi như xong), liệt kê `ListObjectsV2` theo trang, link `PUT` tải thẳng ký kèm
  `content-type` + `x-amz-checksum-sha256` (D-379). Lỗi tạm (mạng, 5xx, 429) thử lại 3 lần.
- **Credential**: khoá ở `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY`; không đặt thì lấy credential tạm của IAM role
  qua dịch vụ metadata của EC2 (IMDSv2: token phiên rồi role rồi credential), giữ tới 5 phút trước hạn — đúng những gì
  `object_store` dựng bằng `AmazonS3Builder::new()` làm (nó không đọc web identity / ECS khi không dựng `from_env`).
- **Ổ đĩa** (`store/local.rs`) tự viết trên `tokio::fs`: ghi file tạm cùng thư mục, `fsync`, đổi tên, `fsync` thư mục
  cha (như `with_fsync(true)`); file tạm bị xoá khi ghi hỏng hay bị huỷ (như `with_automatic_cleanup(true)`); không
  liệt kê file tạm.

Lý do: `rusty-s3` là đúng phần cần (ký SigV4, dựng URL, đọc XML trả về), kiểu sans-IO nên không kéo HTTP client hay
runtime riêng, được bảo trì (bản 18/11/2026), dựng trên đúng `jiff` 1.0, `hmac` 0.13, `sha2` 0.11, `base64` 0.23 repo đã
có, BSD-2-Clause (đã cho phép, D-353). Ổ đĩa chỉ cần vài thao tác tệp — tự viết ít hơn một thư viện.

Đã cân nhắc: tự viết SigV4 (đặc tả công khai, nhưng `rusty-s3` đã làm đúng phần đó và nhỏ); AWS SDK (`aws-sdk-s3`:
rất lớn, kéo `aws-lc-rs` — trái D-043); giữ `object_store` chờ bản bỏ `humantime` (không có mốc); thêm web identity /
ECS (chưa ai dùng — cấu hình chỉ hứa IAM role của máy chủ; thêm sau nếu cần).

Thay: phần "module `files` trên `object_store`" của D-066
