# Getting help

**English** · [Tiếng Việt](SUPPORT.vi.md)

Autoxide is a community project. There is no paid support and no guaranteed response time; maintainers and other users
help when they can.

## Where to ask

| You want to…                                       | Go to                                                                               |
| -------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Install, configure or use Autoxide                 | Read [`README.md`](README.md), [`docs/DEPLOY.md`](docs/DEPLOY.md) and [`docs/guides/`](docs/guides/README.md), then ask in [GitHub Discussions](https://github.com/thuongtamduy/autoxide/discussions) |
| Report a bug                                       | [Open an issue](https://github.com/thuongtamduy/autoxide/issues/new/choose) with the bug template |
| Suggest a feature                                  | Open an issue with the feature template; larger changes use an RFC ([`GOVERNANCE.md`](GOVERNANCE.md)) |
| Report a security problem                          | **Not** in public: follow [`SECURITY.md`](SECURITY.md)                              |
| Report behaviour that breaks the code of conduct   | Follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)                                   |
| Contribute                                         | [`CONTRIBUTING.md`](CONTRIBUTING.md)                                                |
| Build a module                                     | [`docs/MODULE_GUIDE.md`](docs/MODULE_GUIDE.md)                                      |

## Before you ask

- Search the existing issues and discussions.
- Run `autoxide doctor` and include its output: it checks the configuration and the database.
- Say which version, which database (SQLite or PostgreSQL), and how you run Autoxide (binary, Docker, Kubernetes).
- Never paste secrets, tokens or personal data. Remove them from logs first.

## Supported versions

Which versions receive fixes is described in [`SECURITY.md`](SECURITY.md); compatibility between versions in
[`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md).
